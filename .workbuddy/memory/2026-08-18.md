# 2026-08-18 工作日志

## dsh-plugin-security-review 启动崩溃修复（ERR_MODULE_NOT_FOUND）

**症状**：插件以 dev 方式（`~/.dsh/profiles/web/node_modules/dsh-plugin-security-review` → 符号链接指向 `D:\Coding\安全审查插件`）安装后，`npx @deepseek-ai/dsh web` 秒崩：
`Cannot find package '@deepseek-ai/cordis-plugin-loader' imported from D:\Coding\安全审查插件\lib\gate.js`。

**根因**：
1. `lib/gate.js`/`tools.js`/`settings.js` 顶层静态 `import` 了 4 个宿主包（`@deepseek-ai/cordis-plugin-loader`、`@deepseek-ai/dsh-tools`、`@deepseek-ai/dsh-settings`、`schemastery`），但 `package.json` 里 `dependencies` 为空、只声明为 optional peerDependencies。本地文件夹安装时插件不在任何 node_modules 树内，Node ESM 无法解析这些裸导入。
2. 宿主内 schemastery 是**带作用域 fork** `@deepseek-ai/schemastery`（3.18.1），全局没有无作用域 `schemastery`——原代码即使用 `schemastery` 也解析不到，且必须用宿主同一副本保证类身份。
3. 附带发现 `lib/index.js` 末尾 `apply.name = name;` 在 ESM 严格模式下必然抛 TypeError（之前从未执行到，属于潜伏 bug）。

**修复**（模式可复用）：
- 新增 `lib/host.js`：`findDshInstallRoot()` 从 `process.argv[1]`（dsh CLI 入口）向上找 `name == "@deepseek-ai/dsh"` 的 package.json 定位 dsh 安装根（env `DSH_INSTALL_ROOT` 可覆盖）；`hostResolve()`/`hostImport()` 用 `createRequire` 锚定在 `dshRoot/node_modules/__dsh_plugin_anchor__.js` 解析宿主包（注意：`import.meta.resolve(spec, parent)` 在此 Node 版本 parent 参数不生效，会 ERR_MODULE_NOT_FOUND），并优先取 exports["."].import 的 ESM 构建（schemastery 取 .mjs 而非 .cjs），realpath 规范化保证与宿主共享同一模块实例。
- 3 处顶层静态导入改为 apply 内的惰性异步导入；`apply` 改为 async（已确认 cordis-plugin-loader 的 `Entry._init` 会 `await fiber.await()`，异步 apply 被完整等待，门禁安装顺序不受影响）。
- `settings.js` 的 schemastery 修正为 `@deepseek-ai/schemastery`。
- `package.json` 把这 4 个包从 optional peers 移入真实 `dependencies`（版本：cordis-plugin-loader ^1.0.2、dsh-tools/dsh-settings ^0.1.0-rc.6、@deepseek-ai/schemastery ^3.18.1）。

**验证**：
- 模块图独立加载 PASS（原报错点）；模拟 dsh 启动（argv[1] monkeypatch）下 4 个宿主包全部解析到宿主精确路径、EntryTree/defineTool/installSettingsSection/z.object 导出齐全。
- 沙箱内无法做全量启动验证：`npx` 被沙箱 npm-cache EPERM 阻断；直接跑全局 dsh 又在 `prepareProfile` 写 `profiles/web/cordis.yml` 时 EPERM（该文件被某进程锁定/环境权限问题，ACL 正常、非只读——用户机器上 dsh 自己写它没问题，属测试环境 artifact）。需用户自行 `npx @deepseek-ai/dsh web` 确认。

**遗留**：
- `test/analyzer.test.mjs` 中 `extractTgz roundtrip + longname + traversal refusal` 存量失败（与本次改动无关，涉及 analyzer/tar.js）。
- `~/.dsh/profiles/web/__writetest2__.tmp` 测试残留 1 字节文件删除失败（同样被锁），下次 pnpm install 会被清理，无害。
